# HR Bot (Telegram + Google Sheets)

Telegram-бот для HR по ТЗ: учет сотрудников, кадровые изменения, история,
уведомления о днях рождения / годовщинах / испытательных сроках, ежедневный
HR-дайджест и отчеты. Google Sheets — основная база данных.

Стек: **Python 3.11+, aiogram 3, gspread (Google Sheets API)**.

## Структура

```
main.py                 # точка входа
bot/
  config.py             # чтение .env (секреты только тут)
  models.py             # модель сотрудника, роли, колонки листов
  keyboards.py          # все inline-клавиатуры
  middlewares.py        # проверка доступа по Telegram ID
  handlers/             # меню, сотрудники, добавление, поиск, переводы,
                        # увольнения, события, отчет, настройки
  services/
    sheets.py           # репозиторий Google Sheets (единственное место с API)
    events_calc.py      # расчет ДР/годовщин/испытательных сроков (чистая логика)
    notifications.py    # планировщик: уведомления + дайджест + бэкап
    auth.py             # пользователи и роли
    backup.py           # ежедневные резервные копии в backups/
tests/                  # юнит-тесты логики
```

## Установка

```bash
pip install -r requirements.txt
```

## Настройка секретов

Все токены и ссылки хранятся в `.env` (в git не попадает). Пример — `.env.example`:

```
BOT_TOKEN=<токен от @BotFather>
SPREADSHEET_ID=1kRH4iooYH5ixT_Q10WOHhW26ziTvsTfz792VfSOQJV8
GOOGLE_CREDENTIALS_FILE=service_account.json
ADMIN_IDS=
TIMEZONE=Asia/Almaty
DEFAULT_DIGEST_TIME=09:00
```

### Подключение Google Sheets (обязательно, один раз)

1. Откройте https://console.cloud.google.com → создайте проект.
2. Включите **Google Sheets API** и **Google Drive API**
   (APIs & Services → Library).
3. APIs & Services → Credentials → **Create credentials → Service account**.
4. У сервисного аккаунта: Keys → **Add key → JSON** — скачается файл.
   Сохраните его как `service_account.json` в корне проекта.
5. Откройте JSON: поле `client_email` — это адрес вида
   `hr-bot@project.iam.gserviceaccount.com`.
6. **Поделитесь вашей таблицей** с этим email: кнопка «Настроить доступ»
   в таблице → добавить email с правом **Редактор**.

При первом запуске бот сам создаст листы:
«Сотрудники», «История», «Увольнения», «События», «Справочники»,
«Пользователи», «Настройки».

> Примечание к ТЗ: в лист «Сотрудники» добавлена колонка **Филиал**,
> она нужна для карточки и фильтров «По филиалам». Также добавлены служебные
> листы «Пользователи» (авторизация) и «Настройки» (время дайджеста).

### Первый вход

- Админов можно указать в `.env`: `ADMIN_IDS=123456789,987654321`.
- Если список пуст: напишите боту `/start` — он ответит отказом и покажет
  ваш Telegram ID. Внесите ID в `.env` и перезапустите, либо пусть
  существующий админ добавит вас через ⚙ Настройки → Пользователи.

## Запуск

```bash
python scripts/check_setup.py   # диагностика: .env, токен, доступ к таблице
python scripts/seed_demo.py     # (опционально) залить тестовые данные
python main.py                  # запуск бота
```

`seed_demo.py` добавляет ~18 демо-сотрудников с датами относительно сегодняшнего дня:
ДР через 3 дня/сегодня, годовщина через 7 дней, испытательные сроки 7/3/0 дней,
принятый сегодня, уволенные. Удобно, чтобы сразу увидеть уведомления, дайджест и отчет.
Флаг `--force` перезаполняет данные повторно.

Логи пишутся в консоль и `logs/bot.log`. Ошибки Google Sheets не роняют бота:
пользователь получает «⚠ Не удалось сохранить данные», ошибка фиксируется в журнале.

## Роли

| Роль | Возможности |
|---|---|
| Администратор | все операции + настройки доступов, дайджеста, справочников |
| HR | все кадровый операции и отчеты |
| Руководитель | просмотр сотрудников, карточек, истории; получает уведомления |

## Ежедневные задачи

В заданное время (по умолчанию 09:00, часовой пояс UTC+5) бот отправляет:

1. Персональные уведомления: ДР за 3 дня и в день ДР; годовщины за 7 дней
   и в день; испытательный срок за 7 дней, за 3 дня и в день окончания.
2. Общий HR-дайджест со счетчиками по категориям.
3. Резервную копию всех листов в `backups/YYYY-MM-DD.json`
   (хранятся последние 30 дней).

Повторы исключены: каждое отправленное событие логируется в лист «События»
с уникальным ключом (какое событие, кому, когда).

## Тесты

```bash
pip install pytest
pytest tests/
```

Проверяют: парсинг дат, расчет стажа (пример из ТЗ «3 года 20 дней»),
плюрализацию, сдвиги дат, генерацию уведомлений с нужными офсетами,
защиту от дублей и счетчики дайджеста.
